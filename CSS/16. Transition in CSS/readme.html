CSS Transform and Transition — Part 1

Mental model: transform visually moves, spins, resizes, or slants an element. transition makes that change animate smoothly instead of snapping.

1. transform: the four functions

It changes how an element is drawn, not the layout. The original space stays reserved and neighbours don't move.

transform: scale(1.5);              /* both axes */
transform: scale(1.5, 2);           /* x, y */
transform: translate(20px, 20px);   /* x, y */
transform: rotate(70deg);           /* spin, clockwise */
transform: skew(20deg, 10deg);      /* x, y */

Single-axis versions: scaleX/Y, translateX/Y, skewX/Y.

scale = resize, translate = move, rotate = spin, skew = slant.

Defaults when you pass one value:

  • scale(1.5) scales both axes, not just x.
  • translate(20px) moves x only.
  • skew(20deg) skews x only. skewY is the y axis.
Corrections to the class notes
  • rotate() takes one angle and spins flat on the screen. rotate(x, y) is invalid.
  • rotateX() and rotateY() are 3D flips, like flipping a card. They are not what rotate() does.
  • translate(20px 20px) needs a comma.
  • Stray characters fixed: display: flex; and rotate(70deg).

2. Combining functions

transform: translate(20px) rotate(20deg) scale(1.2) skewX(10deg);

transform is not shorthand for separate properties. It is one property that takes a space-separated list of functions. Order matters:

rotate(45deg) translateX(100px)   /* axis rotated first, so it moves diagonally */
translateX(100px) rotate(45deg)   /* moves right, then spins in place */

Each function changes the element's own axes for the ones after it.

A second transform declaration replaces the first. It doesn't add to it.

3. transform-origin

The pivot point for rotate, scale, and skew. translate ignores it. Default: 50% 50% (center).

transform-origin: top left;
transform-origin: 40% 20%;   /* x y, as %, px or keywords */

A third value (z) exists only for 3D and must be a length, not a percentage. If you set transform-origin twice, the second wins.

Origin = the pin you stick through the element before turning it.

4. transition

transition: 0.6s ease;
/* = transition: all 0.6s ease 0s; */
/* = property | duration | timing-function | delay */
  • Property defaults to all.
  • With two times, the first is duration and the second is delay.
  • Common timing functions: ease (default), linear, ease-in, ease-out, ease-in-out.

Put transition on the base rule. That way it animates both into and out of :hover. On :hover alone, it animates in but snaps back. A hover transform replaces the base transform; it doesn't add to it.

Transition vs animation: a transition is one A to B change triggered by a state change. An animation uses keyframes and can loop on its own.

Transition = when this property changes, take 0.6s to get there instead of jumping.

Mental model


transform decides what happens to the element. transform-origin decides where it pivots. transition decides how smoothly it gets there. :hover just flips the state, and transition on the base rule smooths the change in both directions.
