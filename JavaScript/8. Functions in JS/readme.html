JavaScript Functions — Part 6

Mental model: a function is a named recipe. You pass in ingredients (arguments), it runs the steps (body), and it can hand back a result (return).

1. Named functions (declarations)

function sum(a, b) {                 // a, b = parameters
  const result = a + b;
  console.log('Result:', result);    // prints, but gives nothing back
}
sum(70, 1);                          // 70, 1 = arguments

function multiply(c, d) {
  return c * d;                      // hands the value back
}
console.log("4 3's are", multiply(4, 3));   // 4 3's are 12
const result2 = multiply(2, 3);             // 6, stored for later
  • Parameters are the names in the definition. Arguments are the values you pass in.
  • console.log shows a value to you. return gives it to your code, and it also stops the function immediately. A function with no return gives back undefined.
  • result inside sum is local (Part 1), so you could reuse that name outside without a clash.

print = show it. return = hand it back.

2. Calling before the definition

greet();                        // works: Hi, undefined!
function greet(username) {
  console.log('Hi,', username + '!');
}
greet('Pratham');               // Hi, Pratham!

Function declarations are hoisted: JS reads them first, so you can call them above their line. A missing argument makes the parameter undefined, and extra arguments are ignored. The examples use a plain greeting text.

Declaration = usable anywhere in its scope, even above itself.

3. Function expressions (anonymous functions)

const add = function (i, j) {
  const result = i + j;
  return result;
};
add(2, 3);   // 5, but only AFTER the line above

A function expression is a value stored in a variable, so it can only be used after that line has run.

What I corrected
  • The class note said anonymous functions "do not support global hoisting" and must be "declared first". The reason isn't that the function is anonymous, and "global" isn't the issue. add is a variable that only gets its value when the line runs. Calling it earlier gives a ReferenceError with const or let, and a TypeError: not a function with var.
  • i+k should be i+j. k doesn't exist, so calling it would throw a ReferenceError.
  • let became const, since add is never reassigned (Part 1).

Expression = a function stored in a variable, usable once that variable is set.

4. Nested functions


function addSquares(n, m) {
  const a = square(n);
  const b = square(m);
  function square(num) {        // private helper, only exists inside addSquares
    return num * num;
  }
  return a + b;
}
console.log(addSquares(1, 2));  // 5  (1 + 4)

Mental model


A function packs reusable steps. Parameters are the input names, arguments are the actual values, and return is the output (no return means undefined). Declarations are hoisted, so you can call them above their line. Expressions are just values in a variable, so they only work after that line runs. Nested functions are private helpers that live inside their outer function.
