JavaScript Arrow Functions and Callbacks — Part 9

Mental model: a function is just a value. An arrow function is a shorter way to write that value, and a callback is a function you hand to another function to call for you.

1. Three ways to write a function

function greet() { console.log('Hey Everyone!'); }              // named (declaration)
const greet2 = function () { console.log('Good morning'); };    // function expression
const greet3 = () => { console.log('Good morning'); };          // arrow function

The first two are from Part 6. The arrow function is the new, shorter form.

2. Arrow functions

const greet = (count) => { console.log('Hello all!', count); };
const square = (num) => { return num * num; };   // block body: needs return
const square = (num) => num * num;               // concise body: returns automatically

A body without braces returns its value automatically (implicit return). With braces you must write return.

What I corrected
  • The class said "wrap it into a single line", but it isn't about lines. Dropping the braces gives a concise body, and its expression is returned for you.
  • let greet2 and let greet3 became const, since they're never reassigned (Part 1).

Rules to remember:

  • Zero parameters need (). One parameter can skip the parentheses (num => num * num). Two or more need them.
  • To return an object from a concise body, wrap it in parentheses: () => ({ a: 1 }).
  • Arrow functions are function expressions, so they aren't hoisted (Part 6) and only work after their line.

Arrow = (inputs) => output. No braces means the value is returned for you.

3. Callbacks

const calculate = (a, b, operation) => {
  return operation(a, b);
};

// Method 1: anonymous function
const summation = calculate(2, 3, function (n1, n2) { return n1 + n2; });
console.log(summation);          // 5

// Method 2: named function
function sub(a, b) { return a - b; }
const subtraction = calculate(2, 3, sub);     // pass sub, not sub()
console.log(subtraction);        // -1

// Method 3: arrow function
const mult = (a, b) => a * b;
const multiplication = calculate(2, 3, mult);
console.log(multiplication);     // 6
What I corrected

Method 1 in class logged calculate, which prints the function itself, not a result. It should log summation, which is 5.

  • A callback is a function passed as an argument, and the receiving function decides when to call it. This works because functions are values: you can store them, pass them, and return them.
  • Pass the function itself (sub), not sub(). With parentheses you'd call it immediately and pass its result instead.

Callback = "here, you call this for me".

4. Callbacks in array methods

const arr = [2, 5, 6, 8, 0, -3, -5, -2];

const isNegative = (num) => num < 0;

arr.find(isNegative);        // -3  (first item that passes the test)
arr.findIndex(isNegative);   // 5   (its index)

arr.forEach((num, index) => {
  console.log(num, index);   // 2 0, 5 1, ... -2 7
});
What I corrected
  • printFirstNegativeNum doesn't print anything, and it doesn't find anything either. It's a yes/no test, and find or findIndex do the finding. isNegative is a better name.
  • The three "methods" in class are the same test written three ways: concise (num < 0), a block with return num < 0, and a block with if (num < 0) { return num; }. The third returns the number instead of true/false. It only works for negatives because they're truthy (Part 2). A test for 0 written that way would fail, because it returns 0, which is falsy.
  • find returns the first item whose callback result is truthy, or undefined if none pass. findIndex returns its index, or -1 (like indexOf, Part 5). Both stop at the first match.
  • forEach calls the callback for every item with (item, index, array). The order of parameters matters, the names don't. It ignores the callback's return value, and you can't break out of it (Part 4).

find/findIndex = "which one passes this test?" forEach = "do this for each".

Mental model


A function is just a value, so you can store it, pass it, and return it. An arrow function is the short way to write one: (inputs) => output, and with no braces the value is returned for you. A callback is a function you hand to another function, which decides when to call it. Array methods like find, findIndex, and forEach take callbacks. A test callback should return true/false, because find and findIndex only care whether the result is truthy.
