JavaScript Conditionals: if, else, nested if, ternary — Part 8

Mental model: if asks a yes/no question and runs a block only on "yes". else is the "no" path. Nesting asks a second question inside a "yes". The ternary is a one-line yes/no that hands back a value.

1. if and if / else

console.log("First line.");
const candidateAge = 12;

if (candidateAge >= 18) {
  console.log("You're eligible to vote.");
}

if (candidateAge >= 18) {
  console.log("You're eligible to vote.");
} else {
  console.log("You're not eligible to vote yet.");   // runs for 12
}

console.log("Last line.");
What I corrected

"elligible" is spelled "eligible". I also replaced the message texts in the class examples with plain ones, since the logic is what matters here.

  • A lone if runs its block only when true. When false it's skipped, and the program carries on.
  • if / else runs exactly one of the two blocks.
  • Lines outside, like "First line." and "Last line.", always run, in order.
  • Always use braces { }, even for one line.

if = do this only when true. else = otherwise do that.

2. Nested if

if (candidateAge >= 18) {
  if (candidateAge >= 60) {
    console.log("Senior citizens (60 or above) can vote online.");
  } else {
    console.log("You're eligible to vote.");
  }
} else {
  console.log("You're not eligible to vote yet.");
}
What I corrected

The class version had an extra console.log("You're eligible to vote.") after the inner if/else, still inside the outer block. That line runs for everyone 18 and over, so a senior saw both the senior message and "eligible", and a 30-year-old saw "eligible" twice. I removed it. If you wanted both messages on purpose, keep it.

The inner if is only checked when the outer one is true.

Nested = a question asked inside a "yes" answer.

3. The else-if ladder (flatter)

if (candidateAge >= 60) {
  console.log("Senior citizens (60 or above) can vote online.");
} else if (candidateAge >= 18) {
  console.log("You're eligible to vote.");
} else {
  console.log("You're not eligible to vote yet.");
}

This gives the same outcomes as the nested version, but flat. Order matters (Part 7): >= 60 must come before >= 18, or a 70-year-old would match the 18 branch first.

Nested or ladder: same decisions, different shape. Prefer the flatter one.

4. The ternary operator

// condition ? valueIfTrue : valueIfFalse
const message = candidateAge >= 18
  ? "You're eligible to vote."
  : "You're not eligible to vote yet.";
console.log(message);

// or inline:
console.log(candidateAge >= 18 ? "eligible" : "not eligible");
What I corrected
  • The class comment said condition ? True : False, which reads as if it returns booleans. It returns whichever value or expression sits in the true or false slot.
  • The class code put a console.log(...) in each slot. That works, but the ternary is built to produce a value, so pick the value and log once.
  • Use if / else when you need to run several statements.

Ternary = a tiny if/else that hands back a value.

Mental model

Every if is a yes/no question. A lone if acts only on "yes", else covers "no", and nesting asks a follow-up question inside a "yes". The else-if ladder flattens nested questions into one list, strictest first. The ternary compresses a simple if/else into one expression that produces a value.
